## DLSSG Manager

A Windows GUI manager for the [dlssg_for_sm86](https://github.com/sdli1995/dlssg_for_sm86)
proxy mod: game auto-detection with icons, compatibility check, install, log verification and
updates. Russian and English UI.

### Contents

- `DLSSG-Manager.exe` — the GUI (portable, no installation);
- `dlssgm-cli.exe` — console version;
- `README.md`, `LICENSE`.

### Requirements

- Windows 10/11 x64, NVIDIA RTX GPU, driver **R580+**;
- a DirectX 12 game with DLSS Frame Generation support.

### Important

- The exe is not code-signed: SmartScreen may ask for *More info* → *Run anyway*.
- **The mod is not bundled.** The program downloads the author's official GitHub release.
- Not affiliated with NVIDIA Corporation or with the mod author. MIT license, no warranty.
- Installing the mod modifies game files — the risk (including possible bans in online games
  with anti-cheat) is on the user.
